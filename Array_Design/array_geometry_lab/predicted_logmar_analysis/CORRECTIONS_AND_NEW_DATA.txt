[NEW DATASET] Kim et al. (2017) -- added to this analysis for the first time
-----------------------------------------------------------------------------
Kim WS, Park IK, Park YK, Chun YS (2017). "Comparison of Objective and
Subjective Changes Induced by Multiple-Pinhole Glasses and Single-Pinhole
Glasses." J Korean Med Sci 32(5):850-857. DOI: 10.3346/jkms.2017.32.5.850.

Already existed, already vetted, in stage4_human_vision/literature.py under
the key 'single_pinhole_kim_2017', flagged "USABLE as one additional real
(aperture, approx-M, acuity) data point" -- but had never actually been run
through the model before 2026-09-28.

Data used: single-pinhole spectacles, 0.9mm (900um) aperture, N=36 subjects,
mean spherical equivalent -2.7+/-2.3D (range -6.0 to +0.75D, group mean/SD,
NOT per-subject), mean uncorrected LogMAR with pinhole = 0.20 +/- 0.21.

Model prediction at a=900um, M=2.7D: LogMAR = 0.2770.
Deviation from observed: +0.077 logMAR (model PESSIMISTIC here -- the
OPPOSITE direction from the 500/750um array-relevant points, and within 1 SD
of the real data's own spread). This is the key honest finding this anchor
adds: the model's error is not a single universal offset: it flips sign
across the aperture/M range tested.

Literature.py's own fidelity note for this entry should be read alongside
this file -- it already documents the correct caveats (group-mean M and
acuity, not per-subject; single aperture only, no sweep).
