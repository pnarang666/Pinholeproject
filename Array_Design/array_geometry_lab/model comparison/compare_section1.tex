\section{Purpose and Scope}

Shen (Hangzhou Normal University, Aug.\ 2026) addresses the same IYPT 2027
pinhole-sunglass design problem this project addresses, independently. This
document compares the two models directly, quantifies where and why they
diverge on this project's actual candidate data, and states honestly where
each model is stronger. This is a technical comparison, not a claim that
either work supersedes the other in general --- the two studies cover
different, only partially overlapping, regions of the design space.
